Ticket Handling

No response from user:

  • If a user hasn’t replied within 12+ hours, ping them.
  • If there is still no reply after 4 more hours, ping one final time.
  • If there is still no answer after 4 more hours, proceed to close the ticket.
  • If the ticket seems handled, you can issue a /requestclose through chat, and usually members tend to not respond to it, if you do not get a response within 6 hours you can ping them again, and if they don’t respond in another 6-8 hours you can close the ticket.
  • Closing the ticket automatically gives a reason saying the ticket was handled, so you don’t need to give a reason.
  • If a ticket seems like an issue that isn’t related to technical support, you can use /ticket transfer (the needed panel) Move:yes (Ping a needed staff member before you transfer the ticket)
  • for key related issues, such as a key being invalid, ping the someone that is an admin or higher.

User spamming staff:

  • If a user spam-pings staff immediately after opening a ticket or after some time of no response, first warn them to stop and assure them that staff will help soon (or assist them yourself).
  • If they continue to spam, you may time them out for an hour or less depending on the severity of the mass mentioning

Professionalism:

  • Always maintain professional language and conduct when handling tickets.
  • Do not send unneeded gif’s or photos while handling a ticket.

FPS Drops/Stutters

This is usually caused by:

  • Shader cache needing to be rebuilt (AMD/NVIDIA).
  • High temperatures.
  • Power Throttling.

If the user has a X3D Chip:

  • The utility can cause stability issues to X3D Chips.
  • Instruct the user to: Use a system restore point. Avoid CPU tweak options in the utility.

Network Issues After the Tweaks

Network tweaks can sometimes be hit or miss. If the user reports connectivity problems:

  • Option A: Walk them through a Network Reset in Windows Settings -> Network & Internet -> Advanced Network Settings -> Network Reset.

Bluetooth and WiFi Fix

Use the Fixes in the Support server to support the user

Minecraft Installation Issues

  • Direct the user to the official download: https://www.minecraft.net/en-us/download
  • If the launcher fails, have them install Windows Legacy Launcher.
  • If they still have login issues, apply the Xbox gaming Fixes (see Xbox Issues section).

Restore Point Fix

  • Make sure Volume Shadow Copy service is enabled and running.
  • Go to System Protection -> Ensure its enabled, and Max Usage is set to around 10%.
  • If it still doesn’t work: Boot into Safe Mode and try the restore point from there.
  • If restore still fails: Guide the user to perform a Clean Install of Windows.

Peripherals Not Working

If caused by hidusbf:

  • Try a System Restore Point first.
  • If restore is not possible: Unplug the affected device. Open Device Manager → Uninstall the device. Uninstall any USB ports with a yellow warning symbol. Restart the PC → Plug the device back in.

If caused by Tweaking Utility:

  • Attempt a System Restore Point.
  • If normal restore doesn’t work: Boot into Advanced Startup → Run restore point from there.
  • After restoring, advise the user to skip KBM (keyboard/mouse) tweaks.

Additional Fixes

  • Try plugging devices into a different USB port (rear I/O is most reliable).
  • Disable USB selective suspend: Control Panel → Power Options → Advanced Settings → USB Settings → Disabled.
  • For stubborn cases: If still failing, guide the user to perform a Clean Boot to rule out third- party conflicts.

Display Problems

  • Revert GPU Tweaks: Undo any GPU tweaks and restart.
  • Reinstall GPU Driver: Use DDU in Safe Mode for clean removal. Reinstall latest driver from official site.
  • Restore Point / Revert: If still broken, use a System Restore Point

FiveM Fix

  • If the user has issues after tweaks: Run the command: netsh int ip set global mldlevel=all
  • If the issue persists: Perform a Network Reset (Settings → Network → Advanced → Network Reset) Or use the Revert option in the utility.

Blurry / Rigid Text After Tweak

  • Press Win + R, type: SystemPropertiesPerformance
  • Hit Enter → In Visual Effects: Select Adjust for best appearance or Enable Smooth edges of screen fonts.
  • Click Apply → OK.
  • Restart the PC.

Powerplan Importing Issue

  • Open CMD (Command Prompt) as admin or ask Tezzer for a bat file.
  • powercfg /l After that, use this command to apply the exm powerplan (usually the one with no name).
  • powercfg /setactive <GUID>
  • If this fix doesn’t work, use this command -> restart pc and try again.
  • reg add "HKLM\SYSTEM\CurrentControlSet\Control\Power" /v PlatformAoAcOverride /t REG_DWORD /d 0 /f”

Audio Problems

  • Guide the user to reinstall their audio driver to fix most issues.
  • If the problem is caused by setting game priority to High: Inform the user that this behaviour is normal if they have a low-core CPU.

High CPU / RAM Usage

  • This can be normal after using tweaks, but may also result from: An unstable system or Insufficient system specs.
  • Recommended steps for the user: Check Event Viewer for failures or warnings. If issues persist -> Use a System Restore Point to revert changes.

Sleep / Hibernation

  • Restore default power schemes: powercfg –restoredefaultschemes

Windows Updates

  • Enable updates using Windows Update Blocker.
  • If not using the blocker, guide the user to enable required services:
sc config wuauserv start= auto sc config bits start= auto sc config cryptsvc start= auto sc start wuauserv sc start bits sc start cryptsvc

Restart the PC after enabling services to apply changes.

Slow Boots

  • Normal after running the utility because Fast Boot is disabled.
  • The computer fully shuts down and starts all services/apps during boot. No additional action is needed unless other issues appear.

Key Issues

Invalid Key:

  • Ask if the user has spoofed or changed motherboards:
  • If yes -> Direct them to the New Key channel.
  • If no -> Use:
  • /hwid 1 -> Windows 10
  • /hwid 2 -> Windows 11
  • After receiving their HWID and key → Ping a higher staff member.

Blacklisted:

  • Ask the user for their key -> Ping a higher staff member.

Missing Key:

  • Ask for their email -> Ping a staff member with database access.

Proof of ownership:

  • Receipt
  • Ping an Admin+ to swap roles.

Cannot Verify:

  • If this is their only account: Ask for email and receipt → Ping Admin+ to verify manually.
  • If it's not their only account: Follow Old Account Lost/Termed Steps.

Purchasing Using Unsupported Payment:

  • Crypto → Direct to EXM’s DMs.
  • Other unsupported payments (Paysafe, etc.) → Ping a trusted seller staff member to assist.

Refund Policy
